# 图片同步对比工具

Windows 图片 A/B 对比工具：把两张图片放在同一块画布中切换，快速观察补光、修图、压缩或算法处理前后的差异。当前版本为 1.2。

## 下载与启动

**[下载完整可运行版](https://github.com/ylele1479-collab/image-sync-compare/releases/latest)**，下载 `ImageSyncCompare-Windows-v1.2.zip`，全部解压后双击 `ImageCompare.exe`。仓库根目录也提供同一 EXE。

适用 Windows 10/11，使用系统的 .NET Framework 4.x，不需要安装 Python、模型、Node.js 或额外图像工具。若精简版系统缺少 .NET Framework，请启用 Windows 的 .NET Framework 4.x 组件。程序目录需要可写，用于保存目录设置和预览缓存。

## 功能介绍

| 功能 | 说明 |
|---|---|
| 同位置对比 | A/B 图片显示在同一个位置，按空格切换，方便观察细微变化 |
| 双目录导入 | 分别选择原图和处理图目录，按文件名自然顺序逐组配对 |
| 左侧图片目录 | 显示组号及两边文件名，点击任意行直接跳转，翻页同步高亮 |
| 缩放和平移 | 鼠标滚轮缩放，拖动平移，适应窗口后恢复全图 |
| 闪烁对比 | 定时交替显示 A/B，便于发现位置和色彩差异 |
| 高清查看 | 普通浏览使用最长边约 1920 像素的预览，放大后读取原始分辨率 |
| 预载与缓存 | 后台预载前方 10 组、后方 2 组；持久缓存减少重复解码 |
| 目录记忆 | 保存上次选择的两个文件夹，下次启动可恢复 |

支持 JPG、JPEG、PNG、BMP、GIF、TIF、TIFF。仅浏览图片，不改写原图。

## 使用步骤

1. 点击“① 导入文件夹 A”选择原图目录。
2. 点击“② 导入文件夹 B”选择处理结果目录。
3. 检查两边文件名及数量，确认自然排序后确实逐项对应。
4. 按空格切换 A/B，使用 A/D 翻组；也可以直接点击左侧目录。
5. 放大后拖动查看局部；按 0 恢复适应窗口。

| 操作 | 快捷键 |
|---|---|
| 切换 A/B | 空格 |
| 上一组 / 下一组 | A / D，或 ← / → |
| 第一组 / 最后一组 | Home / End |
| 适应窗口 | 0 |
| 开关闪烁 | F |
| 缩放 / 平移 | 滚轮 / 鼠标拖动 |

## 配对和缓存说明

程序按两个目录各自的自然排序位置配对，不按图片内容自动寻找对应关系。数量不一致时仅配对较少的一侧数量，并弹出提示。文件名排序不同可能导致错配，使用前需要确认。

`folders.txt` 保存目录选择；`preview-cache-v1` 保存预览缓存，可能随浏览数量增大。关闭程序后可以删除缓存，下次会重新生成。高清解码速度和内存占用取决于图片尺寸、磁盘和电脑配置。

## 源码与构建

`src/` 包含 C# WinForms 源码。双击 `Build.bat` 使用 Windows 自带的 .NET Framework C# 编译器构建。`ImageCompare.exe` 是发布用便携程序。
